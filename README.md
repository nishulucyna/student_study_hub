# Student Study & Task Hub

A clean, barebones Flutter Web application built for the End Semester Examination, covering all 10 syllabus experiments:

1. **Dart Language Basics** (`lib/dart_basics.dart` & `StudyTask` class)
2. **Flutter Widgets & Layouts** (`Text`, `Image`, `Container`, `Row`, `Column`, `Stack`)
3. **Responsive UI Design** (`MediaQuery` & 700px breakpoint switching between `GridView` and `ListView`)
4. **Navigation & Named Routes** (`Navigator.pushNamed`, `/`, `/add-task`, `/api-quotes`)
5. **State Management** (`StatefulWidget`, `StatelessWidget`, `setState`, and `Provider` / `ChangeNotifier`)
6. **Custom Widgets & Themes** (`CustomTaskCard` reusable widget + Light/Dark `ThemeData`)
7. **Forms & Validation** (`Form`, `GlobalKey<FormState>`, `TextFormField`, `DropdownButtonFormField`, input validation)
8. **Animations** (`AnimationController`, `FadeTransition`, `SlideTransition`, and `AnimatedContainer`)
9. **REST API Integration** (`http.get` from `https://dummyjson.com/quotes?limit=6` with `FutureBuilder`)
10. **Unit & Widget Testing** (`test/widget_test.dart`)
